# 冷跑验收（改技能时当场做，不归审计）

冷跑验证"模型只照文档会不会跑偏"。在**改/建某技能时**做，通过才收工；全库审计（builtin-skill-audit）不重跑冷跑。

## 冷跑四步

①**预判**（冷跑前必做）：先写"我猜弱模型会读偏第 X 条，因为 Z"，再冷调验证。
②**冷调**：起零上下文子代理，只喂该技能文档，让它照正文执行一次。
③**对读**：它对每条判据/步骤的理解与编写意图逐条对照，命中"读歧义/跳步/自创规则/漏读导航行"任一即偏差。
④**修正收工**：有偏差→回正文把该处写成显式判断逻辑（"遇 X 按 Y 因为 Z"+边界 case），再冷调一次。

**两连过**：改完冷调零偏差=第 1 连过；再改完零偏差=第 2 连过；两次连续零偏差才收工，中间任一有偏差计数归零。

## 子代理提示词模板（冷调用）

```
你没有任何背景知识，只能依据这份技能文档判断和动手。文档在 <路径>，先完整读完再执行。
按文档全流程跑一遍，回报：
(1) 你走了哪条分支、实际敲了哪些命令、看到什么结果；
(2) 按文档的回复/交付格式完整回报一次；
(3) 哪句文档让你不确定/看不懂/会跑偏（原话指出是哪一句）。
某步不确定就停下如实说明，别自己发明文档没写的命令。
```

## 漂移抗性（可选深检）

冷调之外再测"理解是否稳定"，用于改大后抽查：
- **重复稳定性**：子代理起 2 次执行同一冷调任务（读技能→按判据执行→输出判定）。起 2 次无子代理工具时，降级为主模型自模拟 2 次独立判读（两次不互看结果）。对照**档位判定**：档位一致=稳；档位不同=判据弱（回正文补锐利锚点）。`builtin-skill-audit` 的 9 项检查中 3 条以上档位读偏=差。
- **换说法触发**：用 3 种说法描述同一需求（原词/同义词/症状词），手动匹配该技能 description 触发词看是否路由到，无需真开会话。漏 1 种=补触发词。

## 子代理可用性判断

- 有 `delegate_task`（或等价零上下文子代理工具）→ 真冷调。
- 没有 → 主模型自模拟，并在交付时标"本次冷跑=降级自模拟，非真零上下文"（可信度打折，下次有子代理补跑）。
